# FL248 English for Tourism — GitHub Pages

This folder contains a static, responsive orientation page for **FL248 — English for Tourism (Tiếng Anh Du lịch)**.

## Files
- `index.html` — complete website (HTML + CSS + JavaScript in one file)

## Publish on GitHub Pages
1. Create a new GitHub repository, for example `FL248-Orientation`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. GitHub will provide the public Pages address after deployment.

## Notes
- The course/class/theory links in the page are the Google Drive URLs from the supplied orientation document.
- The Can Tho University logo is loaded from an official CTU-hosted image URL (`ai.ctu.edu.vn`). A text fallback appears if that remote image cannot load.
- The page uses the CTU brand blue tones indicated on the University branding page.
- No framework or build process is required.
